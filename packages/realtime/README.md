# @parlivo/realtime

The LiveKit client wrapper used by web and desktop: room connection, the track subscription rules (subscribe to `translated-{speakerId}-{lang}` for other speakers in the chosen language, keep originals for same-language speakers, never subscribe to translations of your own speech) and typed data-channel caption and event messages (ARCHITECTURE.md sections 2, 4 and 6).
